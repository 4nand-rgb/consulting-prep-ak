# Hypothesis-Driven Thinking

Consultants start with a possible answer and test it using evidence.

## Process

1. Define problem
2. Create hypothesis
3. Collect evidence
4. Test findings
5. Refine answer

## Healthcare Example

Problem:
Why are NHS waiting lists increasing?

Hypothesis:
Demand is growing faster than capacity.

Evidence:
- workforce data
- referrals
- bed capacity

## Consulting Use

Used in:
- strategy
- healthcare consulting
- case interviews

## Learning Note

This method avoids random analysis and improves focus.
