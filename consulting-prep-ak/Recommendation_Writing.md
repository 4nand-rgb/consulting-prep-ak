# Recommendation Writing

Consulting recommendations should be practical and evidence-based.

## Structure

1. What should happen?
2. Why is it needed?
3. How should it happen?
4. Expected impact

---

## Healthcare Example

Recommendation:
Improve NHS diagnostic capacity using digital scheduling.

Why:
Diagnostic delays increase waiting times.

Impact:
Faster treatment access and improved productivity.

---

## Common Mistakes

- vague recommendations
- unrealistic ideas
- weak evidence

---

## Learning Note

Strong recommendations connect analysis with action.
