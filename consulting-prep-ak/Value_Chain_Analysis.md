# Value Chain Analysis

Value chain analysis studies activities that create value.

## Main Goal

Improve:
- efficiency
- quality
- cost
- service

## Healthcare Example

### NHS Patient Journey

1. GP referral
2. Diagnostics
3. Treatment
4. Follow-up care

## Strategic Questions

- Where are delays happening?
- Which steps add value?
- Which steps increase cost?

## Consulting Use

Used in:
- operational improvement
- patient pathway redesign
- service transformation

## Learning Note

Value chains help identify improvement opportunities.
